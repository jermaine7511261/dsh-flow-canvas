# archify 与 dsh-flow-canvas 集成方案

## 概述

本文档总结了 archify 与 dsh-flow-canvas 的集成路径调研结果，包括技术分析、集成方案设计和实施建议。

## 1. 技术分析

### 1.1 archify 核心功能

archify 是一个基于 AI 的图表生成工具，支持以下 5 种图表类型：

| 图表类型 | 英文名称 | 图标 | 描述 |
|---------|----------|------|------|
| 架构图 | Architecture | 🏗️ | 系统组件和关系 |
| 工作流图 | Workflow | 🔄 | 业务流程和步骤 |
| 序列图 | Sequence | 🔀 | 对象间交互顺序 |
| 数据流图 | DataFlow | 📊 | 数据流动和转换 |
| 生命周期图 | Lifecycle | ♻️ | 对象状态变化 |

**技术特性**：
- **JSON 规格**：使用 JSON 定义图表结构
- **多格式导出**：支持 HTML、PNG、SVG 格式
- **主题切换**：支持暗色/亮色主题
- **动画效果**：支持运动和过渡动画
- **自包含 HTML**：生成独立的 HTML 文件
- **对比功能**：支持 Before/Delta/After 对比

**DSH 插件版本**：
- 已有 `dsh-archify` 插件（GitHub: GongYuanCaiJi/dsh-archify）
- 将 archify 移植为 DSH 插件

### 1.2 dsh-flow-canvas 现有能力

**已有 DiagramNode 组件**：
- **位置**：`src/client/nodes/DiagramNode.tsx`
- **支持图表类型**：架构图、工作流图、序列图、数据流图、生命周期图
- **功能**：预览、主题切换、对比模式指示
- **已注册到节点系统**：在 `nodes/index.tsx` 中注册为 `diagram` 类型

**技术栈**：
- **ReactFlow**：DAG 编辑器库
- **Zustand**：状态管理
- **Dagre**：图布局算法
- **TypeScript**：类型安全

**扩展点**：
- **节点系统**：支持自定义节点类型
- **面板系统**：支持属性面板和节点面板
- **执行引擎**：支持工作流执行

## 2. 集成方案设计

### 方案 A：直接嵌入 archify 图表渲染能力（推荐）

**描述**：将 archify 的渲染引擎直接集成到 DiagramNode 中。

**实现步骤**：
1. 引入 archify 的渲染库（或使用 dsh-archify 插件）
2. 增强 DiagramNode 组件，支持实际图表渲染
3. 实现 JSON 规格到 archify 格式的转换
4. 添加导出功能（HTML/PNG/SVG）
5. 支持主题切换和动画效果

**优点**：
- 直接使用 archify 高质量渲染引擎
- 图表质量有保证
- 功能完整（动画、导出、主题）

**缺点**：
- 需要引入 archify 依赖
- 可能增加包大小（约 100-200KB）
- 需要处理依赖版本兼容性

**工作量**：中等（2-3 天）
**风险**：低（archify 已有成熟实现）

### 方案 B：借鉴 archify 图类型系统，扩展现有 Mermaid

**描述**：基于 archify 的图类型设计，使用 Mermaid 实现渲染。

**实现步骤**：
1. 分析 archify 的 JSON 规格
2. 设计 Mermaid 兼容的图表语法
3. 实现 Mermaid 渲染器
4. 添加主题和动画支持

**优点**：
- 扩展现有系统，保持一致性
- Mermaid 生态成熟
- 包大小增加较少

**缺点**：
- 需要从头实现渲染逻辑
- 渲染质量可能不如 archify
- 动画效果有限

**工作量**：高（5-7 天）
**风险**：中等（渲染质量可能不达标）

### 方案 C：作为独立面板集成 archify 导出能力

**描述**：将 archify 作为独立的图表生成面板。

**实现步骤**：
1. 创建独立的 archify 面板
2. 实现图表生成和预览
3. 添加导出功能
4. 集成到现有界面

**优点**：
- 独立集成，不影响现有系统
- 实现简单
- 风险最低

**缺点**：
- 用户体验不够流畅
- 功能可能不够完整
- 与现有图表节点分离

**工作量**：低（1-2 天）
**风险**：低（功能独立）

## 3. 推荐方案

**推荐方案 A**，理由：
1. **现有基础**：dsh-flow-canvas 已有 DiagramNode 组件，只需增强渲染能力
2. **质量保证**：archify 提供专业级图表渲染
3. **功能完整**：支持动画、导出、主题等高级功能
4. **工作量适中**：2-3 天可完成

## 5. 技术风险

1. **依赖兼容性**：archify 依赖可能与现有依赖冲突
2. **包大小**：archify 渲染库可能增加 100-200KB
3. **主题同步**：需要与 dsh-flow-canvas 主题系统同步
4. **性能影响**：复杂图表可能影响渲染性能
